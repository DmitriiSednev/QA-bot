# Alembic Migrations

This directory contains database migration scripts managed by Alembic. Alembic provides a way to handle database schema changes in a structured and repeatable manner.

## Basic Commands

Make sure your virtual environment is activated and the `.env` file with the correct `DATABASE_URL` is present in the project root before running commands.

**1. Create a new migration script automatically:**

Alembic can often detect changes made to your SQLAlchemy models (in `database/models.py`) and generate a migration script automatically.

```bash
alembic revision --autogenerate -m "Your description of the changes"
```

After running this, review the generated script in the `alembic/versions/` directory to ensure it correctly reflects the intended changes.

**2. Create a new empty migration script:**

If you need to write a migration manually (e.g., for data migrations or complex schema changes).

```bash
alembic revision -m "Your description for manual migration"
```

Then edit the newly created file in `alembic/versions/`.

**3. Apply migrations:**

To apply all pending migrations to your database:

```bash
alembic upgrade head
```

To apply migrations up to a specific revision:

```bash
alembic upgrade <revision_id>
```

**4. Downgrade migrations:**

To revert the last applied migration:

```bash
alembic downgrade -1
```

To revert all migrations:

```bash
alembic downgrade base
```

To revert to a specific revision:

```bash
alembic downgrade <revision_id>
```

**5. Check current status:**

To see the current revision of the database and any pending migrations:

```bash
alembic current
```

To view the history of migrations:

```bash
alembic history
```

## Configuration

-   **`alembic.ini`**: Main configuration file. Defines the database connection string (via `DATABASE_URL` environment variable), logging, and other settings.
-   **`alembic/env.py`**: Script executed by Alembic commands. It sets up the database connection and defines how migrations are run (online/offline) and which metadata (tables) Alembic should track.

## Important Notes

-   Always review autogenerated migration scripts before applying them.
-   Ensure your database connection details in `.env` are correct.
-   Commit migration files to your version control system along with your model changes.
