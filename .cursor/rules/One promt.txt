У меня есть задача сделать проект с QA ботом(или агентом/агентской системой) который отвечает в телеграмме на вопросы пользователя, он должен быть интегрирован в чат в телеграмме. Прочитай что я тебе прислал, проанализируй и скажи мне, у меня есть возможность подключить и делать этот проект через виртуальную машину, или мне его лучше делать локально в терминале power shell моего ноутбука? Предложи архитектуру проекта. Q- это вопрос пользователя, A-это ответ на вопрос пользователя. 
Мой QAботик должен быть примерно такой архитектуры:

graph TD
    subgraph User Interface (e.g., Telegram)
        UI_Input[User Message/Command]
        UI_Output[Bot Response/Status]
    end

    subgraph Core Agent Logic (LangGraph)
        InputGuardrails[Input Guardrails & Validation]
        AgentState[Agent State (memory, context, tool history, intent)]
        Router[Router/Planner Node (LLM-based decision)]
        ToolExecutor[Tool Executor Node]
        ToolOutputGuardrails[Tool Output Validation & Error Handling]
        ResponseGenerator[Response Generation Node (LLM)]
        OutputGuardrails[Output Guardrails (Content safety, formatting)]
    end

    subgraph Tools
        Tool_Search[Search FAQ Tool (Robust error handling, clear description)]
        Tool_Add[Add FAQ Tool (Input validation, confirmation?)]
        Tool_Update[Update FAQ Tool (Input validation, confirmation?)]
        Tool_Delete[Delete FAQ Tool (Confirmation required!)]
        Tool_WebSearch[(Optional) Web Search Tool]
        Tool_DocSearch[(Optional) Yandex Docs Search Tool]
        %% ... potentially more tools
    end

    subgraph Data & Knowledge
        DB[(Database: Supabase/Neon - Postgres)]
        VectorStore{Vector Store (pgvector in DB)}
        Config[Configuration (Prompts, API Keys, Settings)]
    end

    subgraph Monitoring & Logging
        Logger[Logging Service]
    end

    %% Flow
    UI_Input --> InputGuardrails
    InputGuardrails -- Validated Input --> AgentState
    AgentState --> Router
    Router -- Decision: Use Tool --> ToolExecutor
    Router -- Decision: Respond --> ResponseGenerator
    ToolExecutor -- Selects & Prepares Tool --> Tools
    Tools -- Tool Input --> ToolExecutor %% Implicit call
    ToolExecutor -- Raw Tool Output --> ToolOutputGuardrails
    ToolOutputGuardrails -- Validated Tool Result / Error --> AgentState
    ResponseGenerator -- Generates Response --> OutputGuardrails
    OutputGuardrails -- Safe Response --> UI_Output

    %% State Updates & Logging
    InputGuardrails -- Updates / Reads --> AgentState
    ToolOutputGuardrails -- Updates --> AgentState
    OutputGuardrails -- Updates --> AgentState
    Router -- Reads --> AgentState
    ToolExecutor -- Reads --> AgentState
    ResponseGenerator -- Reads --> AgentState

    InputGuardrails -- Logs --> Logger
    Router -- Logs --> Logger
    ToolExecutor -- Logs --> Logger
    ToolOutputGuardrails -- Logs --> Logger
    ResponseGenerator -- Logs --> Logger
    OutputGuardrails -- Logs --> Logger
    Tools -- Logs --> Logger

    %% Data Access
    Tools -- CRUD / Search --> DB
    Tools -- Search / Update --> VectorStore
    AgentState -- Reads --> Config
    Router -- Reads --> Config
    ResponseGenerator -- Reads --> Config
    Tools -- Reads --> Config
